# LIQUID BUBBLE LAUNCHER — iOS 26/27 EDITION

A full-featured Android Home Launcher built with Kotlin, Jetpack Compose, Material 3 foundations, and a 6-layer Liquid Glass & Spatial UI graphics engine.

## Automated Build (GitHub Actions)
Push to `main` or push a version tag (`v1.0.0`) to automatically run unit tests and build `app/build/outputs/apk/debug/app-debug.apk`.
